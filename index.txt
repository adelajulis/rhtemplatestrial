RECRUITHUB TEMPLATE LIBRARY — INDEX
=====================================================================
This is the official online list of RecruitHub templates for its
clients (recruitment and executive search firms). RecruitHub keeps it
up to date. Each template is a plain text file with instructions for
building that document in the client's own brand.

INSTRUCTIONS FOR CLAUDE
The client asked to see or use the RecruitHub templates.
1. Show the list below as a short numbered menu: name + format +
   one line on what it is for. Ask which one they want, or suggest
   one if they already said what they need.
2. When they choose, open ONLY that template's link and follow the
   instructions in it, exactly as if they had attached the file.
3. If a link does not open: tell them in one sentence and ask them
   to attach the same template from the folder 'Prompts - Claude
   templates' in their Claude folder (same number and name).

TEMPLATES
